# Учёт оплаты обучения студентов

Веб-приложение для финансового отдела вуза: договоры на платное обучение, график платежей,
регистрация оплат, расчёт задолженности и пеней, сводный отчёт по должникам.

Разработано в рамках производственной (эксплуатационной) практики,
Университет «Синергия», направление 02.03.03 «Математическое обеспечение и
администрирование информационных систем», кейс-задача № 3
(разработка ПО для проектов в сфере финансовых технологий).

## Возможности

- вход сотрудников по логину и паролю (пароли хранятся в виде хеша);
- карточка студента и договора, автоматический график платежей (1, 2 или 4 платежа в год);
- регистрация оплат с проверками (сумма > 0, не больше остатка, дата не в будущем);
- распределение оплат по графику (FIFO): статусы «Оплачен», «Оплачен частично», «Просрочен», «Ожидается»;
- расчёт пеней: 0,1 % в день от просроченной суммы, не более 10 %;
- поиск по ФИО, группе и номеру договора;
- сводный отчёт и список должников;
- JSON API `GET /api/students/<id>/summary` для интеграции с другими системами.

## Технологии

Python 3.11+, Flask, SQLite, Jinja2, pytest.

## Архитектура

```
app/
  __init__.py   фабрика приложения, настройки, CSRF-защита
  services.py   бизнес-логика: деньги, график, распределение оплат, пени (без БД — легко тестировать)
  db.py         работа с SQLite, команды CLI (init-db, create-admin, seed-demo)
  auth.py       вход/выход, проверка авторизации
  views.py      страницы и JSON API
  schema.sql    схема БД
  templates/    HTML-шаблоны
  static/       стили
tests/          автотесты (pytest)
```

Суммы хранятся в копейках (целые числа), чтобы исключить ошибки округления.

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

flask --app app seed-demo      # база с демо-данными, вход: admin / admin12345
flask --app app run            # http://127.0.0.1:5000
```

Для рабочего режима вместо демо-данных:

```bash
flask --app app init-db
flask --app app create-admin <логин>
SECRET_KEY=<случайная-строка> flask --app app run
```

## Тесты

```bash
pytest -q
```

34 теста: расчёт графика и пеней, распределение оплат, валидация сумм,
авторизация, CSRF, защита от open redirect и SQL-инъекций.

## Жизненный цикл разработки

1. **Анализ требований** — функциональные и нефункциональные требования финансового отдела.
2. **Проектирование** — трёхслойная архитектура (шаблоны → обработчики → бизнес-логика/БД), схема БД.
3. **Разработка** — Flask-приложение, бизнес-логика вынесена в отдельный модуль.
4. **Тестирование** — модульные и интеграционные тесты pytest.
5. **Внедрение** — запуск через `flask run` (для продакшена — gunicorn + nginx + HTTPS).
6. **Поддержка** — миграции схемы, исправление ошибок, развитие по результатам эксплуатации.
